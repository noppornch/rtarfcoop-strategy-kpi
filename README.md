# ระบบบริหารจัดการแผนกลยุทธ์ (Strategic Tracking Web App)

## 1. ระบบสิทธิ์ผู้ใช้งาน (Role-Based Access Control)
* **ผู้ดูแลระบบ (Admin)**:
  * สามารถใช้งานแถบเมนูใหม่ **"จัดการฐานข้อมูล" (phpMyAdmin Lite)** เพื่อเลือกดูโครงสร้าง, ดึงข้อมูล, เพิ่ม, แก้ไข และลบข้อมูลดิบในแต่ละตารางของ SQLite ได้โดยตรง
  * สามารถ CRUD จัดการข้อมูลผู้ใช้, แผนกลยุทธ์ และโครงสร้างทั้งหมด
* **ผู้บริหาร (Manager)**:
  * สามารถเพิ่ม/แก้ไข/ลบกิจกรรมหลัก (KPI Activity) ได้**เฉพาะกลยุทธ์ที่ระบุให้ผู้บริหารคนนั้นๆ เป็นผู้ดูแล** (หากไม่ได้เป็นผู้ดูแล จะไม่สามารถเพิ่ม/แก้/ลบกิจกรรมในกลยุทธ์นั้นได้)
* **ผู้ใช้งานทั่วไป (User)**:
  * สามารถรายงานผลการทำงานเฉพาะกิจกรรมย่อยที่ตนได้รับมอบหมายเป็นผู้รับผิดชอบหลักเท่านั้น
  * **การรายงานผล**: ได้แยกส่วนรายงานความคืบหน้าเพิ่มเติม (Progress Details) ลงไปอยู่ในแต่ละ **ขั้นตอนย่อย (Sub-step)** แทนฟิลด์รวมระดับโครงการ โดยเพิ่มช่อง Textarea ให้พิมพ์รายงานผลลัพธ์รายขั้นตอนได้อย่างชัดเจน

## 2. ข้อมูลระบบสำหรับการทดสอบ (Test Configuration)

**ฐานข้อมูล SQLite จะถูกรีเซ็ตเป็นแบบเปล่า**

ท่านสามารถลงชื่อเข้าใช้งานด้วยผู้ใช้ตัวอย่างที่กำหนดค่าสิทธิ์ไว้ดังนี้:

| Username | Password | Role | สิทธิ์การเข้าใช้งานหลัก |
|----------|----------|------|------------------------|
| **admin** | `admin1234` | Admin (ผู้ดูแลระบบ) | จัดการฐานข้อมูลดิบ SQLite, เพิ่ม/แก้ไข/ลบ แผน, พันธกิจ, กลยุทธ์, ผู้ใช้งาน |
| **manager** | `manager1234` | Manager (ผู้บริหาร) | เพิ่ม/แก้ไข/ลบ กิจกรรมหลักภายใต้กลยุทธ์ที่ดูแล |
| **user1** | `user1234` | User (ผู้ใช้ทั่วไป 1) | บันทึกรายงานผลลัพธ์ระดับขั้นตอนย่อยที่รับผิดชอบ |
| **user2** | `user1234` | User (ผู้ใช้ทั่วไป 2) | บันทึกรายงานผลลัพธ์ระดับขั้นตอนย่อยที่รับผิดชอบ |

## 3. วิธีการรันใช้งานเว็บแอปพลิเคชัน (How to Run)

1. ทำการอัปเดตไฟล์ SQLite ด้วยการรัน:
   ```bash
   node init_db.js
   ```
2. รันสั่งเปิดระบบ:
   ```bash
   npm start
   ```
3. เปิดหน้าต่างบราวเซอร์ที่:
   **[http://localhost:3000](http://localhost:3000)**
